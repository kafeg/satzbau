# content/manual

Данные, которые пишутся руками. Их нельзя получить из источников, и именно они делают
приложение тем, что оно есть.

| файл | что внутри |
|---|---|
| `themes.yaml` | лексические темы: единственный источник лексикона, с уровнями и тегами |
| `templates.yaml` | шаблоны заданий: фраза с одним пропуском плюс условие на наполнение |
| `explain.yaml` | объяснения, один текст на правило |
| `fixes.yaml` | правки к источникам: управление, род омонимов, pl_only, субстантивированные, спорный `aux` |

## Словарь тегов
Теги нужны, чтобы фраза шаблона не теряла смысл. `Ich fahre mit dem Kühlschrank` грамматически
верно и бессмысленно — поэтому шаблон требует `tags: [vehicle]`, а не просто «существительное
из темы Транспорт».

Словарь закрытый. Новый тег добавляется только тогда, когда без него не написать нужный шаблон.

| тег | что помечает |
|---|---|
| `vehicle` | на чём едут: Zug, Bus, Auto, Fahrrad |
| `rail` | рельсовое, подмножество `vehicle` |
| `place` | куда приходят и где находятся: Bahnhof, Haltestelle, Garten |
| `room` | помещение внутри жилья: Küche, Bad, Flur |
| `furniture` | мебель: Tisch, Bett, Schrank |
| `appliance` | техника: Kühlschrank, Waschmaschine, Heizung |
| `thing` | предмет, который можно взять или на который можно показать |
| `food` | еда: Brot, Apfel, Suppe, Lebensmittel |
| `drink` | питьё: Wasser, Kaffee, Bier |
| `body` | часть тела: Kopf, Hand, Zahn |
| `illness` | то, что болит и как это называется: Fieber, Husten, Grippe |
| `weather` | погода: и явление за окном, и безличный глагол о нём — Regen, Nebel, regnen, hageln. Нужен, потому что подлежащее у таких глаголов только `es`: ни `solo`, ни `obj` им не подходят, и до него их не брала ни одна рамка |
| `document` | бумага и билеты: Fahrkarte, Mietvertrag, Anmeldung |
| `person` | человек: Fahrer, Nachbar, Makler |
| `money` | деньги и платежи: Miete, Kaution, Ermäßigung |
| `time` | время и точки расписания: Abfahrt, Ankunft |
| `date` | точка или отрезок календаря: Montag, Sommer, Abend, Woche. Нужен, чтобы «Wann ist der Montag?» не собиралось: вопрос «когда?» задают о событии, а не о самом дне. В «Während …» такие слова, наоборот, идут |
| `abstract` | то, что нельзя показать пальцем: Verspätung, Umzug |
| `noart` | имя собственное без артикля: Deutschland, Europa, Nordpol. Нужен, чтобы «Das ist das Deutschland» не собиралось: у таких имён артикля нет, и рода, который можно спросить, тоже. Страны с артиклем (die Schweiz, die Türkei) его не получают |
| `motion` | глагол движения: fahren, gehen, umsteigen |
| `position` | глагол места: stehen, liegen, sitzen, hängen |
| `placement` | глагол перемещения: stellen, legen, setzen |
| `state` | остальные глаголы: wohnen, kosten, reparieren |
| `obj` | глагол с прямым объектом (переходный): putzen, kaufen, лечить. Без него шаблон с объектом даёт «Ich habe die Wohnung geschlafen» |
| `obj_person` | переходный глагол, у которого объект — человек: füttern, trösten, entlassen. Нужен, чтобы «Er füttert das» не собралось: такие глаголы берут местоимение-человека |
| `surface` | на что можно поставить или положить: Tisch, Boden, Treppe, Balkon |
| `housework` | что делают с жильём: putzen, renovieren, lüften. Нужен там, где объект фразы задан («Ich habe die Wohnung …»): переходности мало, нужен подходящий объект |
| `meal` | приём пищи, а не еда штуками: Frühstück, Mittagessen, Nachtisch. Нужен, чтобы «Ich esse ein Frühstück» не собралось |
| `solo` | глагол, который сам составляет фразу с подлежащим-человеком: «Er kocht», «Er arbeitet». Без него любая рамка без объекта даёт «Er erreicht oft» |
| `quality` | прилагательное |
| `absolute` | прилагательное без степеней сравнения: vegetarisch, unbefristet, schwanger. Без него собирается «am vegetarischesten» |
| `thing_only` | прилагательное только о предмете: breit, eng, modern, bekannt. Нужен, чтобы «Heute ist es breiter als gestern» не собралось: в безличной рамке работают только прилагательные об обстановке |
| `generic` | прилагательное, которое подходит почти к любому предмету: groß, klein, neu, alt, teuer. Нужен там, где существительное приходит вторым словом: без него собирается «die pünktliche Ampel» |

## Правила, которые держат формат простым
- **`{slot}` в рамке один**, `{Slot}` — он же в начале фразы, с заглавной буквы;
- **второе слово `{w2}`** — когда одного слова на фразу не хватает. Условие на него — `fill2`,
  рядом с ним `{art2}` и `{ein2}` (артикли в падеже `fill2.case`). Второе слово не случайное:
  оно ВЫВОДИТСЯ из пары «шаблон + первое слово», поэтому задание по-прежнему восстанавливается
  из журнала ответов. Берётся слово той же темы, если такое есть.
  ⚠ Пары подбираются грамматически, а не по смыслу: «Er kocht das Wohnzimmer» собиралось
  именно так. Для глаголов второе слово поэтому не используется — тег `obj` говорит
  «переходный», а не «берёт ИМЕННО такой объект»;
- **`{particle}`** — отделяемая приставка глагола, вместе с парадигмой `verb_stem`
  (спрягаемая часть без приставки). Так тренируется то, что приставка уезжает в конец;
- **рамка управления собирается из частей**: `{v1}` и `{v3}` — спрягаемая часть без приставки,
  `{mich}` — возвратное `sich` в первом лице, `{pre}` и `{obj}` — то, что в примере управления
  (`fixes.yaml:government_example`) стоит до предлога и после. **Пустые подстановки
  склеиваются**: лишние пробелы и пробел перед точкой убираются, поэтому одна рамка служит
  и отделяемому, и возвратному, и глаголу с прямым дополнением. У глагола с двумя предлогами
  примеров два, и шаблон выбирает нужный полем `nth` в слоте — два шаблона, а не два задания
  из одного: журнал хранит пару «шаблон + слово»;
- **`{art}` и `{ein}`** — определённый и неопределённый артикль, согласованные с родом слова
  и падежом слота (`{Art}`, `{Ein}` — с заглавной). **`{nom}`** — он же, но в именительном:
  подлежащему он нужен независимо от того, какой падеж в пропуске. Без них артикль пишется в рамку буквально,
  и шаблон вынужден фиксировать род условием: так у `adj-dat-en` было три слова наполнения
  вместо одиннадцати;
- **один пропуск на шаблон.** Два пропуска дают комбинаторику в валидаторе и непонятную
  оценку «чего именно человек не знает». Нужны две фразы — пишем два шаблона;
- **все задания — фраза с пропуском**, других форм нет. Упражнение «in + dem = ?» в отрыве
  от фразы отложено: падеж тренируется в предложении, а не в таблице;
- **варианты ответа берутся из инвентаря форм парадигмы**, а не «то же слово в других падежах»:
  у женского рода второе вырождается (Nom `die`, Akk `die`, Dat `der`, Gen `der` — два дубля);
- **условия `need` — закрытый список**: `pos`, `theme`, `tags`, `g`, `lv_max`, `has`, `not`.
  `tags` — **любой из** перечисленных, а не все: слово помечено `document` или `thing`, но не обоими,
  и шаблону нужно «что-нибудь из этих». Условия «все сразу» в формате нет, пока не понадобится;
  `has` принимает и поле записи (`has: [pl]`), и признак (`has: [sep]` — отделяемый):
  так выражается «И», которого в `tags` нет;
  `not` принимает и тег, и признак записи: `pl_only`, `plu`, `npl`, `nd`, `adjdecl`, `mass`,
  `aux_hs`, `aux_s`, `sep` (отделяемый глагол: приставка уедет в конец и сломает рамку),
  `reflexive` (живёт только с sich), `g2` (приняты два рода: «der Laptop» и «das Laptop»,
  поэтому задание «der, die или das» такое слово не берёт), `govex2`;
- **прилагательное в шаблоне фиксировано**, меняется существительное: иначе фразы теряют смысл
  (`eine kleine Anmeldung`).
