# satzbau

Офлайн-PWA для тренировки немецкой грамматики с объяснениями **на русском и через русские падежи**:
падежи, артикли, окончания прилагательных, управление глаголов, времена, порядок слов.
Уровни A1, A2, B1 — и только они: на B2+ дрилл неэффективен.

⚠️ Сейчас это каркас. Кода приложения нет. Есть спека (`docs/spec.md`), проверенные источники
данных (`docs/data.md`) и визуальный язык (`docs/design.md`).

## Стек
Дефолт `../../docs/stack.md`: TypeScript + Vite + React. Сборка даёт статику, она и публикуется.
Отступления от дефолта:
- **бэкенда нет вообще.** Прогресс живёт в IndexedDB на устройстве, экспорт/импорт — JSON-файлом.
  Синк на свой сервер — опционально и позже, напоминания (push) — только вместе с сервером;
- **данные собирает Python**, не фронтовая сборка: отдельный скрипт качает источники и пишет
  компактный JSON под A1–B1. Сырые дампы (около гигабайта) в репозиторий не попадают;
- **озвучка без ассетов**: Web Speech API, системный немецкий голос.

Решение по фронту не финальное: если React с Tailwind окажется тяжелее задачи, упрощаем вплоть
до ванили без сборки, как в соседних игрушках. Критерий — размер бандла и скорость холодного старта
на iPhone в офлайне, не вкус.

## Устройство
```
docs/spec.md    решения, контент-модель, типы упражнений, грамматика по уровням, MVP
docs/data.md    источники, покрытие, лицензии, что нельзя коммитить, открытые вопросы по данным
docs/design.md  визуальный язык, экраны, чего в макетах ещё нет
```
Приложения ещё нет. Когда появится — здесь будет карта `src/`.

## Правила
- **Ветки: только `main`**, коммит и пуш прямо в `main`.
- **Публичный репозиторий.** Ни секретов, ни личных данных, ни внутренних адресов, ни личных ссылок.
- **Лицензии содержимого — жёстко.** Код MIT. Сгенерированные данные — CC BY-SA 4.0 с атрибуцией
  источников (`docs/data.md`). В репозиторий **не попадают**: сырые дампы источников; список лемм
  Goethe (это неофициальная копия защищённых PDF); любые данные под `NC`-лицензией. Скрипт сборки
  скачивает источники сам, на машине пользователя.
- **Проект не предполагает инфраструктуру автора**: ни NAS, ни VPN, ни своего сервера. Всё, что
  может понадобиться снаружи, настраивается конфигом и по умолчанию выключено.
- **Спека перед кодом.** Крупный шаг сначала описываем в `docs/`, потом делаем, с остановкой после этапа.
- Комментарии в коде — минимум, однострочники.
