# satzbau

Офлайн-тренажёр немецкой грамматики для русскоязычных, уровни A1–B1. Объяснения на русском.

⚠️ **Идёт v2: переписываем с модели данных.** v1 заморожена в ветке `v1` (тег `v1-final`);
сайт https://kafeg.github.io/satzbau/ показывает последнюю сборку v1, пока у v2 нет первого
упражнения. Публикации из `main` сейчас нет: workflow вернётся вместе с приложением.

| где | что |
|---|---|
| `docs/data-model.md` | модель данных v2: слои, источники, слово, фраза, база, проверки, порядок работ |
| `TODO.md` | что делаем сейчас |
| `words/` | база слов, правда проекта (появится с импортом) |
| `sentences/` | фразы Tatoeba с разметкой и переводами (появится с импортом) |
| `evidence/` | выписки источников по нашим словам, по ним проверяет CI |
| `tools/` | скачивание, импорт, проверка, сборка базы |
| ветка `v1` | всё прежнее: приложение, шаблоны, объяснения, морфология с тестами |

## Как запускать
| что | как |
|---|---|
| питон 3.12 (spaCy) | `uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r tools/requirements.txt` |
| скачать источники | `.venv/bin/python -I tools/fetch.py` — в `data/raw/`, по `sources.lock`; большие — в 8 соединений |
| импорт существительных | `.venv/bin/python -I tools/import_nouns.py` — ⚠ перезаписывает `words/nouns`: после ручных правок не запускать |
| фразы | `.venv/bin/python -I tools/import_sentences.py` (`--no-nlp` — только отбор, без разметки) |
| проверка | `.venv/bin/python -I tools/verify.py` (`-v` — все ошибки) |

## Правила
- **Только нужное текущему шагу, но архитектурно правильно.** Будущему — шов, не код.
- **Ни одного факта о слове без источника.** Род, формы, перевод подтверждаются по таблице
  в `docs/data-model.md`; иначе `decided` с причиной. Слова не придумываются.
- **Ветки:** работа в `main`, коммит и пуш прямо в `main`. `v1` только читаем: оттуда берём
  нужное по мере надобности (`git checkout v1 -- <путь>`).
- **Публичный репозиторий.** Ни секретов, ни личных данных, ни внутренних адресов.
- **Лицензии содержимого — жёстко.** Код MIT, данные CC BY-SA 4.0 с атрибуцией. В репо не
  попадают: сырые дампы, списки лемм Goethe и производное от них, данные под `NC`, текст
  из книг под копирайтом.
- Комментарии в коде — минимум, однострочники. Документ описывает текущее состояние, не историю.
