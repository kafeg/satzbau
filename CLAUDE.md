# satzbau

Офлайн-PWA для тренировки немецкой грамматики с объяснениями **на русском и через русские падежи**:
падежи, артикли, окончания прилагательных, управление глаголов, времена, порядок слов.
Уровни A1, A2, B1 — и только они: на B2+ дрилл неэффективен.

⚠️ Сейчас это каркас. Кода приложения нет. Решены: схемы данных, размер бандла, модель генератора
заданий, алгоритм повторов. Не решены: ручные списки тем и шаблоны заданий.

| где | что |
|---|---|
| `docs/architecture.md` | устройство целиком: слои и границы, сборка данных, ядро, повторы, хранилище, офлайн, публикация |
| `docs/plan.md` | план работ этапами, с остановками после каждого |
| `docs/spec.md` | решения, контент-модель, генератор заданий, типы упражнений, повторы, MVP |
| `docs/data.md` | схемы JSON, замеренные размеры, источники, управление, чистка, отбор лемм |
| `docs/design.md` | визуальный язык, экраны, чего в макетах нет |
| `TODO.md` | состояние и ближайшие работы |

## Стек
Дефолт `../../docs/stack.md`: TypeScript + Vite + React. Сборка даёт статику, она и публикуется.
Отступления и уточнения:

- **бэкенда нет вообще.** Прогресс в IndexedDB: журнал ответов плюс производное состояние.
  Экспорт и импорт — JSON-файлом. Синк на свой сервер и push-напоминания — позже и опционально;
- **данные собирает Python**, не фронтовая сборка: скрипт качает источники и пишет компактный
  JSON. **Собранный JSON коммитится** (~300 КиБ, это и есть результат под CC BY-SA); сырые
  дампы (1,4 ГБ) — нет, версии пинятся в `sources.lock`. Иначе Pages нечем собирать;
- **весь A1–B1 едет в бандле** — около 300 КиБ в gzip, замерено. Докачки по темам нет;
- **повторы — `ts-fsrs`** (MIT). Единица повтора — правило, слово — второе измерение;
- **озвучка без ассетов**: Web Speech API, системный немецкий голос.

Решение по фронту не финальное: если React с Tailwind окажется тяжелее задачи, упрощаем вплоть
до ванили без сборки. Критерий — размер бандла и скорость холодного старта на iPhone в офлайне,
не вкус.

## Правила
- **Ветки: только `main`**, коммит и пуш прямо в `main`.
- **Публичный репозиторий.** Ни секретов, ни личных данных, ни внутренних адресов, ни личных ссылок.
- **Лицензии содержимого — жёстко.** Код MIT. Сгенерированные данные — CC BY-SA 4.0 с атрибуцией
  (`README.md`, `docs/data.md`). В репозиторий **не попадают**: сырые дампы источников; списки
  лемм Goethe и любое производное от них; данные под `NC`-лицензией. Скрипт сборки скачивает
  источники сам, на машине пользователя.
- **Отбор слов — через ручные списки тем**, не через частотность: бытовая лексика A1 сидит
  на частотных рангах 10–35 тысяч и при отборе по частотности теряется.
- **Задания не хранятся.** Хранятся шаблоны; задание собирается из шаблона и слова, ответ
  и дистракторы считаются по парадигме в коде. Закрытые парадигмы в данных не дублируются.
- **Проект не предполагает инфраструктуру автора**: ни NAS, ни VPN, ни своего сервера.
- **Спека перед кодом.** Крупный шаг сначала описываем в `docs/`, потом делаем, с остановкой
  после этапа.
- Комментарии в коде — минимум, однострочники.
