# satzbau

Офлайн-тренажёр немецкой грамматики для русскоязычных, уровни A1–B1. Объяснения на русском.

v2 строится с модели данных; v1 заморожена в ветке `v1` (тег `v1-final`).
Сайт https://kafeg.github.io/satzbau/ — v2: CI на каждый пуш в `main` проверяет данные
и приложение и публикует сайт. Красная проверка — сайт не меняется.

| где | что |
|---|---|
| `docs/data-model.md` | модель данных v2: слои, источники, слово, фраза, база, проверки, порядок работ |
| `docs/app.md` | приложение: слои, упражнение, журнал, повторы, сборка урока |
| `docs/rules.md` | правила грамматики: источники, проверка на словаре, подсказки |
| `docs/ex-gender.md` | упражнение «Род»: какие слова, экран, урок |
| `docs/ex-plural.md` | упражнение «Множественное число»: типы, какие слова, экран |
| `TODO.md` | что делаем сейчас |
| `words/` | база слов, правда проекта (появится с импортом) |
| `themes/` | темы: упорядоченные списки id слов, решение (из отбора v1) |
| `sentences/` | фразы Tatoeba с разметкой и переводами (появится с импортом) |
| `evidence/` | выписки источников по нашим словам, по ним проверяет CI |
| `tools/` | скачивание, импорт, проверка, сборка базы |
| `src/` | приложение: `core/` — чистая логика, `store/` — база и журнал, `ui/` — экраны (`docs/app.md`) |
| ветка `v1` | всё прежнее: приложение, шаблоны, объяснения, морфология с тестами |

## Как запускать
| что | как |
|---|---|
| питон 3.12 (spaCy) | `uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r tools/requirements.txt` |
| скачать источники | `.venv/bin/python -I tools/fetch.py` — в `data/raw/`, по `sources.lock`; большие — в 8 соединений |
| импорт существительных | `.venv/bin/python -I tools/import_nouns.py` — ⚠ перезаписывает `words/nouns` и стирает решения `decided`: **сейчас не запускать** |
| темы | `.venv/bin/python -I tools/import_themes.py` — ⚠ перезаписывает `themes/`: после ручных правок не запускать |
| фразы | `.venv/bin/python -I tools/import_sentences.py` (`--no-nlp` — только отбор, без разметки; `--relink` — заново привязать токены к словам по готовой разметке, без spaCy: после правок слов и правила привязки) |
| примеры для слов без фраз | `.venv/bin/python -I tools/import_examples.py todo` → задание LLM-сессии; потом без `todo` — разметка в `sentences/wikt/`, `sentences/gen/` |
| правила | `.venv/bin/python -I tools/import_rules.py` — доля правил на словаре и сложные слова в `evidence/`; `tools/check_sources.py` — источники говорят то, на что ссылаемся (нужна сеть); `tools/test_rules.py` — тесты |
| проверка | `.venv/bin/python -I tools/verify.py` (`-v` — все ошибки) |
| база приложения | `npm run data` → `build/satzbau.sqlite` и `.gz` (нужен только PyYAML: системный `python3` без него — `.venv/bin/python -I tools/build.py`) |
| приложение | `npm ci`, `npm run dev` (http://localhost:5173/satzbau/); `npm run check` — типы и тесты, тесты базы требуют `npm run data` |
| боевая сборка | `npm run build && npm run preview` — с service worker; офлайн проверять тут, не в `dev` |

## Правила
- **Только нужное текущему шагу, но архитектурно правильно.** Будущему — шов, не код.
- **Ни одного факта о слове без источника.** Род, формы, перевод подтверждаются по таблице
  в `docs/data-model.md`; иначе `decided` с причиной. Слова не придумываются.
- **Ветки:** работа в `main`, коммит и пуш прямо в `main`. `v1` только читаем: оттуда берём
  нужное по мере надобности (`git checkout v1 -- <путь>`).
- **Публичный репозиторий.** Ни секретов, ни личных данных, ни внутренних адресов.
- **Лицензии содержимого — жёстко.** Код MIT, данные CC BY-SA 4.0 с атрибуцией. В репо не
  попадают: сырые дампы, списки лемм Goethe и производное от них, данные под `NC`, текст
  из книг под копирайтом.
- **Правило грамматики — только из данных** (`docs/rules.md`): два свободных источника, проверка на
  словаре или фразах, сила считается. Ответ проверяется по фактам, правило лишь объясняет.
- **Решено отложить до первого упражнения на таблицы** (окончания прилагательных, артикль в падеже):
  карточка станет «упражнение + элемент» (слово или клетка правила) — `docs/app.md`, «Карточка и
  элемент»; у правил появятся свои виды проверки — `docs/rules.md`, «Дальше». Раньше не делать.
- Комментарии в коде — минимум, однострочники. Документ описывает текущее состояние, не историю.
