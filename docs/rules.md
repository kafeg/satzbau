# Правила грамматики как данные

Правило — проверяемое утверждение о немецком: «-ung → die», «сложное слово берёт род последней
части». Приложение показывает его после ответа как подсказку. Правила не пишутся из головы: у
каждого — источники и проверка на словаре; доля и исключения считаются, а не вписываются.

## Файлы
| что | где |
|---|---|
| правила по темам | `rules/<тема>.yaml` (сейчас `gender.yaml`) |
| источники | `rules/sources.yaml`: адрес и лицензия |
| доля правила на всём словаре | `evidence/rules.jsonl` — `tools/import_rules.py` по `data/raw` |
| последняя часть сложных слов базы | `evidence/heads.jsonl` — тот же скрипт, `dewikt` и `enwikt` |
| выбор подсказки для слова | `tools/hints.py` — один код для `verify.py` и `build.py` |
| проверки | `tools/checks/rules.py` (в `verify.py`), `tools/test_rules.py`, `tools/check_sources.py` |
| в базе | `rules` (id, field, value, text, n, ok, sources) и `hints` (word_id, field, rule_id, ok, head) |

## Правило
```yaml
- id: suffix-ung
  when: {suffix: ung}          # одно условие: suffix | list (с title) | head
  then: {gender: f}            # что утверждает: одно поле слова и его значение
  sources:                     # минимум два разных источника
    - {src: en-wp-gender, at: Noun forms, find: "''-ung,''"}
    - {src: de-wp-genus, at: Deklinationsklasse, find: "''-ung''<sup>''(f)''</sup>"}
```
- `suffix` — слово кончается так (без учёта регистра) и длиннее окончания хотя бы на две буквы.
  Это окончание, а не суффикс: der Sprung попадает под -ung и становится исключением.
- `list` — закрытый список слов (времена года и месяцы); `title` — подпись в подсказке.
- `then` — поле из `FIELDS` в `tools/hints.py` (сейчас только `gender`) и значение; `head` —
  «как у последней части». Новое поле (тип множественного, вспомогательный глагол) — строка в
  `FIELDS` и в `TRUTH` там же; выбор подсказки, проверки и таблицы базы не меняются.
- `head` — род последней части сложного слова. Последняя часть берётся из `dewikt`
  («Determinativkompositum aus … und X») или из `enwikt` (шаблон compound), а у слов без своей
  статьи — из поля `compound`. Подсказка есть, только если род этой части совпал с родом слова.
- `at` — раздел страницы, `find` — строка, которая в этом разделе есть дословно.

## Источники
Только свободные сайты: Википедия, Викисловарь, Wikibooks (CC BY-SA). Список и что в них искать —
`research/` владельца; сюда попадает только то, на что правило ссылается. Источник не из списка
не собирается. Правило с одним источником не собирается — даже если оно верно на словаре:
-ion, -tät, -ik, -ie, -ismus, -ment, -um, -us, -nis, дни недели и стороны света ждут второго.

## Сила правила
Доля — сколько существительных `dewikt` (одного рода, ≈120 тысяч) правило касается и у скольких
род совпал. Сила считается из доли, в данных её нет:

| доля | сила |
|---|---|
| ≥ 95% | правило |
| 80–95% | чаще всего |
| 60–80% | часто |
| < 60% | редко |

Подсказка показывает силу и долю: «-e → die · чаще всего, 87% слов словаря».

## Подсказка для слова
Подсказка считается при сборке базы, а не при ответе: приложение только читает её из `hints`.
Ответ проверяется по фактам слова (`docs/app.md`, «Упражнение»), правило лишь объясняет. Из
правил, что подходят слову, берётся самое надёжное, которое даёт род слова. Если ни одно не
даёт — подсказка «исключение» из самого надёжного подходящего: das Auge — исключение из -e → die.
Нет подходящего правила — нет подсказки: короткие частые слова (der Tisch, die Frau) учат с
артиклем. Подсказка показывается и при верном, и при неверном ответе.

## Проверки
`verify.py` (в CI) не собирает базу, если:
- у правила меньше двух разных источников, нет `at` или `find`, источник не из списка;
- у правила больше одного условия или нет выписки в `evidence/rules.jsonl`;
- в правиле или его источниках есть пометка `llm:`.

Исключения среди слов базы — предупреждения со списком: их видно, но они не ошибка.

`tools/test_rules.py` (в CI) подсовывает проверке выдуманные правила — один источник, один
источник дважды, чужой сайт, пометку LLM, правило без проверки на словаре, два условия — и ждёт
ошибку; и проверяет выбор подсказки на настоящих словах (Zeitung, Kinderzimmer, Auge, Kuchen).

`tools/check_sources.py` (нужна сеть, не в CI; при правке `rules/`): открывает каждую страницу,
находит раздел `at` и строку `find`.

## Дальше
Те же правила для других тем — таблицы (склонение артикля и прилагательного проверяются по
таблицам словоформ `dewikt`), управление (предлог + падеж — по пометкам `with-dative` в `dewikt`
и по фразам), порядок слов (по фразам, когда в разметке появится синтаксическая связь).
