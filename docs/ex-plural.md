# Упражнение «Множественное число»: тип формы

Второе упражнение. Слово с артиклем — какой тип у его множественного: окончание и, если нужно,
умлаут. Данные — `words` и `tokens` базы; урок, повторы и журнал — общие (`docs/app.md`).
Код: `src/core/exercises/plural.ts`, экран — `src/ui/exercises/Plural.tsx`. `id`: `plural`.

## Типы
Пять окончаний и умлаут основы:

| кнопка | что | примеры |
|---|---|---|
| `-e` | -e, и с удвоением s | Tisch → Tische, Bus → Busse, Ergebnis → Ergebnisse |
| `-er` | -er | Kind → Kinder |
| `-(e)n` | -n, -en, -nen после -in | Lampe → Lampen, Frau → Frauen, Lehrerin → Lehrerinnen |
| `-s` | -s | Auto → Autos |
| `—` | без окончания | Lehrer → Lehrer |
| `¨-e` · `¨-er` · `¨` | умлаут одной гласной основы; бывает только с `-e`, `-er`, `—` | Zahn → Zähne, Haus → Häuser, Apfel → Äpfel |

Тип выводится из пары «лемма → форма» (`parse`), а не хранится: исправили форму в данных —
изменился и тип.

## Какие слова
Существительные курса: `number` не `pl`, род есть, множественное есть, в `skip` нет `plural`,
и **первая форма укладывается в пять типов**. Формы вне типов не спрашиваются: на экран не
выводится ни одной неправильной формы, кнопки — это правила, а не слова.

Замер на текущей базе: из 1968 слов курса с множественным в типы укладываются 1937. Остальные 31 —
латинские и греческие формы (Museum → Museen, Firma → Firmen, Visum → Visa) и три настоящих
исключения: Werkstatt → Werkstätten и -saal → -säle. Для них нужна своя подача.

`after: gender`: новая карточка слова открывается, когда по роду этого слова уже был ответ.
Сначала учим артикль, потом форму; поэтому на карточке множественного артикль уже виден.

Засчитывается тип любой формы из списка (Konto: Kontos → `-s`). Разбор показывает ту форму,
тип которой совпал с ответом, иначе первую.

## Экран
Собран из общих частей (`docs/app.md`, «Экран ответа»); упражнение даёт им данные — `src/ui/exercises/Plural.tsx`.
- **Карточка:** над словом артикль цветом рода — он известен, это не вопрос; слово, перевод, `die …?`.
- **Восемь готовых типов** `-e` · `¨-e` · `-er` · `¨-er` · `-(e)n` · `-s` · `—` · `¨`, по четыре в ряд, клавиши 1–8.
  Одно нажатие — один ответ. Умлаутные — только если в основе есть a, o или u (`typesFor`): иначе
  они сами подсказывали бы ответ, и у Kind кнопок пять.
- **После ответа:** как у рода (`docs/ex-gender.md`): нажатая зелёная или красная с «ты», верная при ошибке — пунктир с «верно».
- **Панель ответа** — как у рода, в том же порядке:
  - формы `der Zahn · die Zähne`, изменённые буквы (умлаут и окончание) выделены;
  - заметка при ошибке — как образована верная форма: «без окончания, форма не меняется», «окончание -e
    и умлаут u → ü»; если окончание угадано — «окончание угадал, не хватило умлаута»;
  - правило типа, если оно есть у слова в данных (`rules/plural.yaml`, `docs/rules.md`):
    `data.hint(word.id, 'plural')` — «-ung → -(e)n · правило, 99%», «-chen → —», «как у последней
    части: Zimmer» или «исключение из die → -(e)n» (die Hand). Правило судит о первой форме слова: если
    ответ совпал с другой его формой («также»), правило не показываем — оно бы ей противоречило;
  - пример — самая короткая фраза, где слово стоит во множественном числе (разметка `Number=Plur`).
- Цвет рода — только у артикля единственного числа; `die` множественного — жёлтый, как в курсе.
- Подача одна — основная (`hows: ['word']`).

## Чего нет
Ввода формы с клавиатуры, падежных форм множественного (`den Kindern`), подачи для 31 формы
вне типов.
