# Упражнение «Множественное число»: тип формы

Второе упражнение. Слово с артиклем — какой тип у его множественного: окончание и, если нужно,
умлаут. Данные — `words` и `tokens` базы; урок, повторы и журнал — общие (`docs/app.md`).
Код: `src/core/exercises/plural.ts`, экран — `src/ui/exercises/Plural.tsx`. `id`: `plural`.

## Типы
Пять окончаний и умлаут основы:

| кнопка | что | примеры |
|---|---|---|
| `-e` | -e, и с удвоением s | Tisch → Tische, Bus → Busse, Ergebnis → Ergebnisse |
| `-er` | -er | Kind → Kinder |
| `-(e)n` | -n, -en, -nen после -in | Lampe → Lampen, Frau → Frauen, Lehrerin → Lehrerinnen |
| `-s` | -s | Auto → Autos |
| `—` | без окончания | Lehrer → Lehrer |
| `ä ö ü` | умлаут одной гласной основы; бывает только с `-e`, `-er`, `—` | Zahn → Zähne, Haus → Häuser, Apfel → Äpfel |

Тип выводится из пары «лемма → форма» (`parse`), а не хранится: исправили форму в данных —
изменился и тип.

## Какие слова
Существительные курса: `number` не `pl`, род есть, множественное есть, в `skip` нет `plural`,
и **первая форма укладывается в пять типов**. Формы вне типов не спрашиваются: на экран не
выводится ни одной неправильной формы, кнопки — это правила, а не слова.

Замер на текущей базе: из 1968 слов курса с множественным в типы укладываются 1937. Остальные 31 —
латинские и греческие формы (Museum → Museen, Firma → Firmen, Visum → Visa) и три настоящих
исключения: Werkstatt → Werkstätten и -saal → -säle. Для них нужна своя подача.

`after: gender`: новая карточка слова открывается, когда по роду этого слова уже был ответ.
Сначала учим артикль, потом форму; поэтому на карточке множественного артикль уже виден.

Засчитывается тип любой формы из списка (Konto: Kontos → `-s`). Разбор показывает ту форму,
тип которой совпал с ответом, иначе первую.

## Экран
- **Карточка:** артикль цветом рода и лемма, перевод, ниже `die …?`.
- **Переключатель умлаута** `ä ö ü` — только если в основе есть a, o или u: иначе он сам
  подсказывал бы ответ. Клавиша U.
- **Пять кнопок** `-e` · `-er` · `-(e)n` · `-s` · `—`, клавиши 1–5. Нажатие кнопки и есть ответ
  (с текущим положением переключателя).
- **После ответа:**
  - верное окончание обведено, выбранное неверное зачёркнуто и помечено крестиком (у «-e» и «—»
    зачёркивание сливается с дефисом), остальные приглушены;
  - переключатель: «нужен · не выбран» (пунктир) или «не нужен» (зачёркнут);
  - строка разбора по частям: «Неверно: окончание верное, нужен умлаут»;
  - `der Zahn · die Zähne`: в форме подсвечено, что меняется, — умлаут и окончание; строка
    правила «окончание -e и умлаут: a → ä»;
  - пример — самая короткая фраза, где слово стоит именно во множественном числе (разметка
    `Number=Plur`). Такая фраза есть у 1052 слов курса; у остальных примера нет.
- Цвет рода — только у артикля единственного числа; у `die` множественного цвет нейтральный.

## Чего нет
Ввода формы с клавиатуры, падежных форм множественного (`den Kindern`), подачи для 31 формы
вне типов.
