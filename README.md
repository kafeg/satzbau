# satzbau

Тренажёр немецкой грамматики для русскоязычных: падежи, артикли, окончания прилагательных,
управление глаголов, времена и порядок слов. Уровни A1, A2, B1.

Объяснения на русском и через русские падежи. Не «`mit` + Dativ, запомни», а: по-русски
«на поезде» — предложный, «с кем/чем» — творительный, а немецкий `mit` требует дательного,
без вариантов → `mit dem Zug`.

Работает офлайн: ставится на домашний экран, прогресс хранится на устройстве и выгружается в файл.
Озвучка — системным голосом браузера, своих аудиофайлов нет.

⚠️ **Статус: приложения пока нет.** Готовы спека, схемы данных, модель генератора заданий,
визуальный язык и проверка источников: весь A1–B1 с примерами укладывается в ~300 КиБ gzip,
так что офлайн здесь буквальный, без докачки.

## Запуск
Появится вместе с кодом.

Данные в репозитории не лежат: их собирает скрипт, который скачивает открытые источники
на вашу машину. Это сделано нарочно — так лицензии источников остаются соблюдёнными,
а репозиторий не раздувается.
