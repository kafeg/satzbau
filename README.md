# der Satzbau

Офлайн-тренажёр немецкой грамматики для русскоязычных, уровни A1–B1. Объяснения на русском
и через русские падежи.

⚠️ **Статус: переписывается (v2).** Новая версия строится от базы слов: каждое слово —
одно значение, каждый факт о нём подтверждён открытыми словарями, примеры — живые фразы
Tatoeba с переводами. Модель данных — [docs/data-model.md](docs/data-model.md).
Прежняя версия — ветка [`v1`](../../tree/v1).

Сейчас в v2 два упражнения на 2080 существительных курса A1–B1, по 31 теме: род (`der`, `die`,
`das`) и тип множественного числа. Повторы — FSRS, прогресс хранится на устройстве и переносится файлом.
Запуск: `npm ci && npm run data && npm run dev` (для `npm run data` нужен Python с PyYAML).
