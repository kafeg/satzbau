# satzbau

Тренажёр немецкой грамматики для русскоязычных: падежи, артикли, окончания прилагательных,
управление глаголов, времена и порядок слов. Уровни A1, A2, B1.

Объяснения на русском и через русские падежи. Не «`mit` + Dativ, запомни», а: по-русски
«на поезде» — предложный, «с кем/чем» — творительный, а немецкий `mit` требует дательного,
без вариантов → `mit dem Zug`.

Работает офлайн: ставится на домашний экран, прогресс хранится на устройстве и выгружается в файл.
Озвучка — системным голосом браузера, своих аудиофайлов нет.

⚠️ **Статус: рабочая версия, наполнение продолжается.** Работают дрилл и разбор ошибки, приложение ставится на домашний
экран и открывается без сети. Шесть тем, 573 слова, 25 шаблонов на 15 правил — около восьмисот
заданий; тренировать можно отдельное правило, отдельную тему или всё вперемешку. Ошибки
возвращаются по расписанию (FSRS), прогресс хранится на устройстве и выгружается файлом.
Чего ещё нет: карточек новых слов, таблиц и настроек.

## Запуск
```bash
npm install
npm run dev
```
Откроется на `http://localhost:5173/satzbau/`. `npm run build` собирает статику в `dist/`,
`npm run preview` показывает её вместе с service worker — офлайн проверяется только так.
`npm run check` — типы и тесты.

Пересобрать данные из источников (нужен Python и ~210 МБ дампов) — `tools/`, порядок команд
в [CLAUDE.md](CLAUDE.md). Для работы с приложением это не нужно: собранные данные уже в репозитории.

Что лежит в репозитории, а что нет: **собранные данные лежат** — это компактный JSON
на ~300 КиБ, тот самый результат под CC BY-SA 4.0. **Сырые дампы источников не лежат**:
это 1,4 ГБ, и их скачивает скрипт сборки, когда данные нужно обновить. Версии источников
пинятся в `sources.lock`.
